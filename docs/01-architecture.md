# 1. Архитектура лаборатории

[Главная страница](../README.md)

Я построил лабораторию вокруг Windows-станции менеджера и сервера управления секретами. Для централизованного мониторинга я использовал Wazuh, а для обработки оповещений — TheHive, Cortex и Shuffle.

![Размещение четырёх VM](../diagrams/deployment.png)

## Виртуальные машины

Я выделил виртуальным машинам следующие ресурсы:

| Узел             | ОС                              | Назначение                  | IP               | vCPU |   RAM |   Диск |
| ---------------- | ------------------------------- | --------------------------- | ---------------- | ---: | ----: | -----: |
| `soc-wazuh`      | Ubuntu Server 24.04             | Manager, Indexer, Dashboard | `192.168.31.227` |    3 |  5 GB | 125 GB |
| `app-secrets`    | Ubuntu Server 24.04             | Сервис управления секретами | `192.168.31.210` |    3 |  3 GB |  60 GB |
| `soar-ir`        | Ubuntu Server 24.04             | TheHive, Cortex, Shuffle    | `192.168.31.209` |    6 | 16 GB | 150 GB |
| `win10-endpoint` | Windows 10 Enterprise LTSC 2019 | Рабочая станция менеджера   | `192.168.31.236` |    2 |  4 GB |  60 GB |

## Физические хосты

| Хост                | Адрес            | Ресурсы                    | Размещённые VM              |
| ------------------- | ---------------- | -------------------------- | --------------------------- |
| Ноутбук, Arch Linux | `192.168.31.123` | 12 ядер, 16 GB RAM, 512 GB | `soc-wazuh`, `app-secrets`  |
| ПК, Windows 11      | `192.168.31.110` | 12 ядер, 32 GB RAM, 1 TB   | `soar-ir`, `win10-endpoint` |

Я использовал VirtualBox и общую сеть `192.168.31.0/24`. Ansible запускал через WSL на Windows 11.

## Назначение компонентов

**Wazuh** я использовал для сбора телеметрии, корреляции событий, контроля файлов, оценки настроек и инвентаризации уязвимых пакетов.

**Shuffle** я настроил для приёма оповещений и выбора обработки по идентификатору правила. Из сценария я обращался к API TheHive и Cortex.

**TheHive** я использовал для Alerts, observables, комментариев и тестовых Cases. Observable — это отдельный объект анализа: IP, домен, URL или хеш.

**Cortex** я подключил для запуска анализаторов и получения дополнительного контекста об индикаторах.

**Secret manage service** я разместил на `app-secrets`. Через его API Ansible получает пароли управления. Этот же сервис я использовал как цель двух API-тестов.

## Контейнеры SOAR

| Компонент     | Версия / тег | Для чего я его использовал     |
| ------------- | ------------ | ------------------------------ |
| TheHive       | 5.7.3        | Оповещения и расследования     |
| Cortex        | 4.0.1        | Анализаторы                    |
| Shuffle       | `latest`     | Автоматизация                  |
| Cassandra     | 4.1          | Хранение данных TheHive        |
| Elasticsearch | 8.17.4       | Поисковое хранилище стека      |
| OpenSearch    | 3.2.0        | Хранилище Shuffle              |
| Nginx         | 1.27-alpine  | Доступ к интерфейсам через TLS |

Для исполнения анализаторов Cortex я использовал Docker runner. При настройке Shuffle я работал с сетями Docker и исполнением заданий через Swarm.

## Основные соединения

| Откуда             | Куда            | Способ                 | Назначение                           |
| ------------------ | --------------- | ---------------------- | ------------------------------------ |
| Ansible            | Linux VM        | SSH, TCP 22            | Управление                           |
| Ansible            | Windows VM      | WinRM, HTTP/TCP 5985   | Управление                           |
| Ansible            | `app-secrets`   | HTTPS API, TCP 8443    | Получение паролей                    |
| Агенты             | Wazuh           | TCP 1514               | Передача событий                     |
| Новый агент        | Wazuh           | TCP 1515               | Регистрация                          |
| Клиенты приложения | `app-secrets`   | HTTP 8080 / HTTPS 8443 | Работа с сервисом                    |
| Wazuh              | Shuffle         | HTTP webhook, TCP 80          | Передача оповещений                  |
| Shuffle            | TheHive         | API                    | Создание Alerts и передача контекста |
| Shuffle / TheHive  | Cortex          | API                    | Анализ индикаторов                   |
| Cortex             | Внешние сервисы | API                    | Обогащение                           |

Для приложения я опубликовал Nginx, а FastAPI и PostgreSQL оставил во внутренней сети контейнеров. Для интерфейсов SOAR использовал имена `thehive.soar.local`, `cortex.soar.local`, `shuffle.soar.local` и локальные самоподписанные сертификаты.

Я не внедрял отдельную VLAN-сегментацию и отказоустойчивость. Отказ Wazuh прерывает централизованное обнаружение, отказ SOAR — дальнейшую автоматизацию, а недоступность приложения влияет на получение паролей Ansible.
